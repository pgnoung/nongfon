# ต่อกล้องยี่ห้อต่าง ๆ

← กลับ [README](../README.md)

## ลืมรหัสผ่านกล้อง? (กู้รหัสเดิมไม่ได้ ต้องตั้งใหม่)

รหัสเดิมที่ลืมไปแล้วอ่านกลับมาไม่ได้ (กล้องเก็บแบบถอดกลับไม่ได้) — วิธีที่ถูกต้องคือ **ตั้งรหัสใหม่** ผ่านแอปหรือปุ่มรีเซ็ตของกล้องเอง:

- **Tapo** (เช่น C200): ง่ายสุด ไม่ต้องรู้รหัสเก่า — ในแอป Tapo แตะกล้อง → ⚙️ → **Advanced Settings → Camera Account** ตั้งชื่อผู้ใช้/รหัสใหม่ (6–32 ตัว) แล้วเอามาใช้กับน้องฝนได้เลย
- **Foscam** (R4M/S41): ถ้ายังเปิดแอปดูภาพได้และจำรหัสเดิมได้ เปลี่ยนที่ **เปิดภาพกล้อง → Settings → Security Settings** · ถ้าลืมสนิท กด **ปุ่ม Reset ค้าง 10–15 วินาที** (ใช้คลิปหนีบกระดาษจิ้ม) จนไฟกะพริบและกล้องรีบูต แล้ว login ครั้งแรกด้วย `admin` เว้นรหัสว่าง ระบบจะให้ตั้งใหม่ · หลังรีเซ็ตต้องเพิ่มกล้องเข้าแอปใหม่
- **RISCO VUpoint** (กล้อง/เครื่องบันทึก): กล้องพวกนี้ผูกกับเครื่องบันทึก/ระบบกันขโมย **อย่าเพิ่งกดรีเซ็ตเอง** เพราะอาจต้องให้ช่างจับคู่ใหม่ — ให้กู้รหัสผ่านทาง **แอป/เครื่องบันทึก RISCO** (login เป็น admin) หรือถามช่างที่ติดตั้ง · ค่าเริ่มต้นจากโรงงาน (ถ้าไม่เคยเปลี่ยน) พิมพ์ไว้บนสติกเกอร์กล้อง: ผู้ใช้ `admin` รหัส `_AdmiN_` ตามด้วย MAC ของกล้อง

> ตั้งรหัสใหม่แล้วกลับมาที่ **ตั้งค่า → กล้อง → ค้นหากล้องในบ้าน** พิมพ์รหัสใหม่ กดทดสอบได้เลย

## วิธีที่ง่ายที่สุด: ให้น้องฝนหากล้องให้ (แนะนำ)

ในหน้า **ตั้งค่า → กล้อง** กด **“ค้นหากล้องในบ้าน”** น้องฝนจะสแกนหากล้องในวง Wi‑Fi (ผ่าน ONVIF) แล้วขึ้นรายการให้
จากนั้นแต่ละกล้องแค่พิมพ์ **ชื่อผู้ใช้/รหัสผ่านของกล้อง** (ไม่ใช่รหัสแอปบนมือถือ) แล้วกด **“ทดสอบการต่อ”** —
น้องฝนจะถามลิงก์ RTSP/ภาพนิ่งจากตัวกล้องเอง ลองดึงภาพมาให้ดู ถ้าได้ก็กด **“เพิ่มกล้องนี้”** ใช้งานได้ทันทีโดยไม่ต้องแก้ไฟล์
ถ้ากล้องไม่ขึ้นในรายการ ใช้ **“เพิ่มด้วย IP เอง”** พิมพ์ IP กับยี่ห้อ (เช่น RISCO VUpoint = Dahua) แล้วทดสอบได้เหมือนกัน

- รหัสผ่านไม่ออกนอกเครื่อง — น้องฝนคุยกับกล้องในบ้านเท่านั้น (บล็อกทุกปลายทางที่ไม่ใช่ 192.168.x.x / 10.x / 172.16–31.x)
- กล้องที่เพิ่มจากหน้านี้เก็บไว้ในเครื่อง (`data/user-cameras.json`) เอาออกได้จากปุ่มถังขยะข้างชื่อกล้อง
- ยี่ห้อที่รู้จักลิงก์ให้เลย: RISCO VUpoint/Dahua, Hikvision/HiLook, Foscam, Reolink, TP‑Link Tapo/VIGI, Tiandy, Uniview และ ONVIF ทั่วไป

ถ้าอยากตั้งเองผ่านไฟล์ `.env` (เช่นรันบนเซิร์ฟเวอร์) ยังทำได้ตามด้านล่าง —

น้องฝนต้องการ **ลิงก์ที่ดึงภาพจากกล้องได้** อย่างใดอย่างหนึ่ง:

| แบบ | หน้าตา | ต้องมี ffmpeg? |
|---|---|---|
| **RTSP** (เจอบ่อยสุด) | `rtsp://ชื่อผู้ใช้:รหัส@192.168.1.50:554/...` | ต้องมี (Docker มีให้แล้ว) |
| **ภาพนิ่ง HTTP** | `http://ชื่อผู้ใช้:รหัส@192.168.1.50/snapshot.jpg` | ไม่ต้อง (รองรับ Basic/Digest และสตรีม MJPEG) |
| **go2rtc** | `http://host.docker.internal:1984/api/frame.jpeg?src=หน้าบ้าน` | ไม่ต้องในน้องฝน (go2rtc จัดการเอง) |
| **ไฟล์/โฟลเดอร์** | `/path/to/latest.jpg` หรือโฟลเดอร์ (ใช้ไฟล์ใหม่สุด) | ไม่ต้อง — เหมาะกับการทดสอบ |

ใส่ในไฟล์ `.env` ตัวละ 2 บรรทัด (สูงสุด 12 ตัว):

```dotenv
CAMERA_1_NAME=หน้าบ้าน
CAMERA_1_URL=rtsp://ชื่อผู้ใช้:รหัส@192.168.1.50:554/stream1
CAMERA_2_NAME=โรงรถ
CAMERA_2_URL=http://admin:รหัส@192.168.1.51/cgi-bin/snapshot.cgi
```

> ลิงก์อาจต่างกันตามรุ่นและเฟิร์มแวร์ — หลังเริ่มโปรแกรม ไปที่ **ตั้งค่า → กล้อง → ทดสอบ** จะเห็นภาพทันทีว่าลิงก์ใช้ได้ไหม
> ถ้ารหัสผ่านมีอักขระพิเศษ ให้เข้ารหัสแบบ URL เช่น `@` → `%40`, `#` → `%23`, `:` → `%3A`

## TP-Link Tapo (C200, C210, C310, C320WS, C520WS …)

1. แอป Tapo → เลือกกล้อง → ⚙️ → **Advanced Settings → Camera Account** → ตั้งชื่อผู้ใช้/รหัส (คนละชุดกับบัญชี TP-Link)
2. ดู IP ของกล้องได้ที่ **Device Info**

```
rtsp://ชื่อผู้ใช้:รหัส@IPกล้อง:554/stream1    ← ภาพชัด (แนะนำ)
rtsp://ชื่อผู้ใช้:รหัส@IPกล้อง:554/stream2    ← ภาพเล็ก ประหยัดเน็ต
```

## Hikvision / HiLook

```
rtsp://admin:รหัส@IPกล้อง:554/Streaming/Channels/101
http://admin:รหัส@IPกล้อง/ISAPI/Streaming/channels/101/picture     ← ภาพนิ่ง (Digest — น้องฝนรองรับ)
```

เครื่องบันทึก NVR: ช่องที่ 2 = `201`, ช่องที่ 3 = `301` …

## Dahua / Imou

```
rtsp://admin:รหัส@IPกล้อง:554/cam/realmonitor?channel=1&subtype=0
http://admin:รหัส@IPกล้อง/cgi-bin/snapshot.cgi                      ← ภาพนิ่ง (Digest)
```

กล้อง Imou ใช้ **Safety Code** ที่สติกเกอร์ใต้กล้องเป็นรหัส และบางรุ่นต้องเปิดการดูผ่าน LAN ในแอปก่อน

## EZVIZ

บางรุ่นต้องเปิด RTSP/การดูผ่าน LAN ในแอปก่อน รหัสคือ **Verification Code** ใต้กล้อง

```
rtsp://admin:VERIFICATIONCODE@IPกล้อง:554/h264/ch1/main/av_stream
```

## Reolink

```
rtsp://admin:รหัส@IPกล้อง:554/h264Preview_01_main
http://IPกล้อง/cgi-bin/api.cgi?cmd=Snap&channel=0&user=admin&password=รหัส   ← ภาพนิ่ง
```

## Xiaomi / Mi Home / IMILAB

กล้องตระกูลนี้ไม่มี RTSP ในตัว ให้ใช้ **[go2rtc](https://github.com/AlexxIT/go2rtc) เวอร์ชัน 1.9.14 ขึ้นไป** ซึ่งล็อกอิน Mi Home ครั้งเดียวแล้วแปลงเป็น RTSP/ภาพนิ่งในวง LAN

1. ดาวน์โหลด go2rtc ของเครื่องคุณจาก [releases](https://github.com/AlexxIT/go2rtc/releases) แล้วรันในเทอร์มินัล (macOS: รันตรง ๆ ดีกว่ารันใน Docker)
2. เปิด `http://127.0.0.1:1984` → **Add → Xiaomi** → ล็อกอินบัญชี Mi Home → เลือกกล้อง → จะได้ stream ชื่อตามที่ตั้ง
3. ใส่ในน้องฝน:

```dotenv
# น้องฝนรันใน Docker ส่วน go2rtc รันบนเครื่องเดียวกัน
CAMERA_1_URL=http://host.docker.internal:1984/api/frame.jpeg?src=ชื่อstream
# หรือแบบ RTSP
CAMERA_1_URL=rtsp://host.docker.internal:8554/ชื่อstream
```

> `api/frame.jpeg` ของ go2rtc ต้องใช้ ffmpeg บนเครื่องที่รัน go2rtc ด้วย (macOS: `brew install ffmpeg`) ถ้าไม่มี ให้ใช้ลิงก์ RTSP แทน

go2rtc ยังช่วยกล้องยี่ห้ออื่นที่ต่อยาก (Tuya, กล้องที่ต้องผ่านคลาวด์ ฯลฯ) ได้อีกหลายแบบ ดูรายการในหน้า go2rtc

## กล้องราคาประหยัด / ไม่รู้ยี่ห้อ (V380, ICSee, …)

- ลองใช้โปรแกรม **ONVIF Device Manager** (Windows) หรือแอป **Onvifer** (Android) ค้นหากล้องในบ้าน จะเห็นลิงก์ RTSP ให้คัดลอก
- ลิงก์ที่เจอบ่อย: `rtsp://IP:554/live/ch00_0`, `rtsp://admin:@IP:554/onvif1`, `rtsp://IP:554/11`
- กล้องที่ดูได้เฉพาะในแอปคลาวด์ของยี่ห้อ อาจต่อไม่ได้ — ลองดูว่า go2rtc รองรับไหม

## ทดสอบลิงก์ด้วยตัวเอง

```bash
# ดึงภาพ 1 เฟรมจาก RTSP (มี ffmpeg)
ffmpeg -rtsp_transport tcp -i "rtsp://ชื่อผู้ใช้:รหัส@192.168.1.50:554/stream1" -frames:v 1 test.jpg

# ภาพนิ่ง HTTP
curl --digest -u admin:รหัส -o test.jpg "http://192.168.1.51/cgi-bin/snapshot.cgi"
```

หรือเปิดลิงก์ RTSP ในโปรแกรม **VLC** (Media → Open Network Stream)

## วางกล้องยังไงให้น้องฝนดูแม่น

- **มองเห็นจุดที่น้ำจะมาถึงชัด ๆ** — พื้นหน้าประตู ขั้นบันได ขอบฟุตบาท ผนังที่ไม่ถูกบัง
- **มุมเฉียงลงพื้น** ดีกว่ามองขนานพื้น (เห็นขอบน้ำชัดกว่า)
- **กลางคืน** แสงอินฟราเรดสะท้อนผิวน้ำจนขาวฟุ้งได้ — ถ้ามีไฟส้มหน้าบ้านเปิดทิ้งไว้ ภาพจะอ่านง่ายขึ้นมาก
- เช็ดเลนส์ และกันหยดฝนเกาะ (มีหลังคาบังเล็กน้อย) — หยดน้ำบนเลนส์ทำให้ภาพเบลอ
- **ขีดเส้นบนสิ่งที่ไม่ขยับ** (ขั้นบันได ขอบคาน) ไม่ใช่บนรถหรือของที่ย้ายได้
- ตั้ง **IP คงที่** ให้กล้องในเราเตอร์ (DHCP reservation)
