# แจ้งเตือนและไซเรน

← กลับ [README](../README.md)

ตั้งได้หลายช่องทางพร้อมกัน ทุกข้อความและทุกครั้งที่ไซเรนดังจะบันทึกไว้ในหน้า **ย้อนหลัง → การแจ้งเตือน** พร้อมผลการส่งของแต่ละช่องทาง

## Telegram (แนะนำ ฟรี และสั่งงานกลับได้)

1. ทัก **@BotFather** → `/newbot` → คัดลอกโทเคน → ใส่ `TELEGRAM_BOT_TOKEN=` ใน `.env` → เริ่มโปรแกรมใหม่
2. เปิดแชทกับบอทของคุณแล้วกด **Start** — หรือเพิ่มบอทเข้า **กลุ่มครอบครัว** แล้วพิมพ์ `/start`
3. หน้าเว็บ **ตั้งค่า → Telegram** จะมีปุ่ม **“ใช้แชทนี้”** ขึ้นมา กดแล้วกด **ส่งข้อความทดสอบ**

ความปลอดภัย: บอทรับคำสั่งจาก **แชทที่ผูกไว้เท่านั้น** ใครอื่นทักบอทจะได้แค่ข้อความแนะนำ

| คำสั่งในแชท | ทำอะไร |
|---|---|
| `/status` หรือพิมพ์ “สถานะ” | สถานะล่าสุด + รูปจากทุกกล้อง |
| `/check` หรือ “ตรวจ” | ตรวจเดี๋ยวนี้แล้วส่งผลกลับมา |
| `/stop` หรือ “หยุด” | ปิดไซเรน |
| `/mute` หรือ “งดจนน้ำลด” | งดเสียงไซเรนจนกว่าน้ำจะลดต่ำกว่าระดับตอนนี้ (ข้อความยังส่ง) |
| `/snooze 60` หรือ “เงียบ 60” | งดเสียงไซเรน 60 นาที (ยกเลิกเองเมื่อน้ำกลับสู่ปกติ) |
| `/resume` | ยกเลิกงดเสียง |

ข้อความเตือนเรื่องน้ำมีปุ่ม **🔕 หยุดไซเรน · 😴 งดเสียงจนน้ำลด · ⏱ งด 1 ชม. · 🔄 ตรวจอีกรอบ** ใต้รูปด้วย

> ให้ข้อความของบอทปลุกได้จริง: เปิดเสียงแจ้งเตือนของแชทนี้ให้ดัง และเพิ่ม Telegram เป็นข้อยกเว้นของโหมดห้ามรบกวน/โฟกัสบนมือถือ

## LINE (ผ่าน LINE Official Account)

LINE Notify ปิดบริการตั้งแต่ปี 2025 จึงต้องใช้ **LINE OA + Messaging API** แทน (ข้อความแจ้งเตือนมีไม่กี่ข้อความต่อเดือน อยู่ในโควตาฟรีได้สบาย)

1. สร้าง LINE Official Account ของบ้านที่ [LINE Official Account Manager](https://manager.line.biz/) → เปิดใช้ **Messaging API**
2. ไปที่ [LINE Developers Console](https://developers.line.biz/console/) → channel ของ OA → แท็บ **Messaging API** → ออก **Channel access token (long-lived)**
3. ใส่ `LINE_CHANNEL_ACCESS_TOKEN=` ใน `.env` → เริ่มโปรแกรมใหม่
4. ให้คนในบ้าน **แอด OA เป็นเพื่อน** (สแกน QR ใน OA Manager)
5. หน้าเว็บ **ตั้งค่า → LINE** ใส่ผู้รับเป็น `broadcast` (ส่งถึงทุกคนที่แอด — ง่ายสุด) หรือ User ID ของคุณ (ขึ้นต้นด้วย `U` ดูได้ที่แท็บ Basic settings → *Your user ID*) → **ส่งข้อความทดสอบ**

LINE ได้ข้อความตัวอักษร (ไม่มีรูป เพราะ LINE ต้องการลิงก์รูปที่เปิดจากอินเทอร์เน็ตได้)

## Webhook (ต่อเข้าระบบอื่น)

ใส่ `WEBHOOK_URL=` แล้วทุกการแจ้งเตือนจะ `POST` JSON แบบนี้:

```json
{
  "event": "critical",
  "title": "น้ำถึงเส้นแดง",
  "text": "🚨 น้ำถึงเส้นแดงแล้ว! ตื่นเร็วค่ะ\n🏠 บ้านของเรา · ระดับ 100/100 · 02:22 …",
  "site": "บ้านของเรา",
  "time": "2026-09-26T19:22:28.000Z",
  "status": "critical",
  "level": 100,
  "headline": "น้ำถึงเส้นแดงในโรงรถแล้ว",
  "reasons": ["โรงรถ: ขอบน้ำถึงเส้นแดงแล้ว"],
  "readingId": "r…",
  "cameras": [{ "name": "โรงรถ", "ok": true, "line": "at_red", "note": "…" }]
}
```

`event` เป็นได้: `critical` · `warning` · `recovery` · `failure` · `camera` · `summary` · `test`

ตัวอย่าง: ต่อ Make.com / n8n ให้ส่งต่อไป LINE กลุ่ม, โทรออกอัตโนมัติ, เปิดไฟทั้งบ้าน ฯลฯ

## ไซเรน

### ไซเรน Zigbee ผ่าน zigbee2mqtt

ต้องมี MQTT broker (เช่น Mosquitto) และ zigbee2mqtt ที่จับคู่ไซเรนไว้แล้ว

```dotenv
MQTT_URL=mqtt://ชื่อผู้ใช้:รหัส@192.168.1.5:1883
```

หน้าเว็บ **ตั้งค่า → ไซเรนปลุก**:

1. **Topic** = `zigbee2mqtt/<ชื่ออุปกรณ์ใน z2m>/set`
2. **ชนิดอุปกรณ์** — เลือกให้ตรงกับไซเรนของคุณ:

| ชนิด | ข้อความเปิด | ข้อความปิด |
|---|---|---|
| ไซเรน Tuya/NEO | `{"alarm":true}` | `{"alarm":false}` |
| ไซเรน IAS/Heiman | `{"warning":{"mode":"emergency","level":"very_high","strobe":true,"duration":60}}` | `{"warning":{"mode":"stop"}}` |
| ปลั๊กอัจฉริยะที่เสียบไซเรน/ไฟ | `{"state":"ON"}` | `{"state":"OFF"}` |

3. เปิด **“เปิดไซเรนจริงเมื่อน้ำถึงเส้นแดง”** → กด **ทดสอบไซเรน 3 วินาที**

ดูว่าอุปกรณ์ของคุณรับคำสั่งแบบไหนได้ที่หน้าอุปกรณ์ใน zigbee2mqtt (แท็บ Exposes) · ใช้ MQTT แบบเข้ารหัสได้ด้วย `mqtts://…:8883`

### ไซเรน/ปลั๊กที่สั่งผ่านลิงก์

```dotenv
SIREN_WEBHOOK_ON_URL=…
SIREN_WEBHOOK_OFF_URL=…
SIREN_WEBHOOK_METHOD=POST    # หรือ GET สำหรับอุปกรณ์ที่สั่งด้วยลิงก์ธรรมดา
```

| อุปกรณ์ | เปิด | ปิด |
|---|---|---|
| Home Assistant (webhook automation) | `http://HA:8123/api/webhook/nongfon_siren_on` | `http://HA:8123/api/webhook/nongfon_siren_off` |
| Shelly (Gen 1) | `http://IP/relay/0?turn=on` | `http://IP/relay/0?turn=off` |
| Tasmota | `http://IP/cm?cmnd=Power%20On` | `http://IP/cm?cmnd=Power%20Off` |

Home Assistant: ทำ automation ที่ trigger เป็น **Webhook** (id ตามลิงก์) แล้วสั่งไซเรน/ลำโพง/ไฟตามต้องการ — น้องฝนส่ง JSON `{"siren":"on","reason":"…"}` ไปด้วย

### มือถือหรือแท็บเล็ตเก่าข้างเตียง (ไม่ต้องซื้ออะไร)

1. เปิด `http://<IP เครื่องที่รันน้องฝน>:8080/bedside` บนมือถือเครื่องที่จะวางข้างเตียง แล้วล็อกอิน
2. แตะ **“เปิดเสียงเตือนบนเครื่องนี้”** (เบราว์เซอร์ต้องการการแตะ 1 ครั้งก่อนจึงจะส่งเสียงได้)
3. เสียบชาร์จ เปิดเสียงให้ดังสุด ปิดโหมดห้ามรบกวน
4. ตั้งเครื่องไม่ให้ล็อกจอเอง (หน้านี้ขอให้จอไม่ดับให้แล้วถ้าเบราว์เซอร์รองรับ) — iPhone/iPad: Settings → Display & Brightness → Auto-Lock → Never · Android: เปิด “Stay awake” ใน Developer options ระหว่างชาร์จ

เมื่อไซเรนของน้องฝนดัง หน้านี้จะส่งเสียงไซเรน สั่น และจอกะพริบแดง พร้อมปุ่ม **หยุดเสียงเตือน** ตัวใหญ่ · ถ้าขาดการเชื่อมต่อกับน้องฝนนานเกินไป จะขึ้นเตือนและมีเสียงเบา ๆ

อยากให้ดังตั้งแต่เส้นเหลืองด้วย: ตั้งค่า → ไซเรนปลุก → **ให้หน้า “ข้างเตียง” ดังตั้งแต่เส้นเหลือง**
