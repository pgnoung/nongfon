# คำถามทีละขั้น (question bank)

ถามทีละ 1 คำถาม ให้ตัวเลือกเป็นเลขข้อ มีค่าแนะนำ และบอกเหตุผลสั้น ๆ ว่าถามไปทำไม
ห้ามถามค่าลับในแชท — ทุกค่าลับให้ผู้ใช้พิมพ์เองด้วย `cd <โฟลเดอร์> && bash install/nongfon.sh secrets` (Windows: ดับเบิลคลิก `NongFon-windows.bat` → เมนู 3) หรือในหน้าเว็บ

## ขั้น 1 — ติดตั้งในเครื่องนี้ (local)

> “น้องฝนจะติดตั้งในเครื่องนี้เครื่องเดียวนะคะ เพื่อความปลอดภัย ภาพกล้อง รหัสกล้อง และคีย์ทั้งหมดจะอยู่ในบ้านคุณ
> ที่ออกนอกบ้านมีแค่ภาพที่ส่งให้ AI ดู กับข้อความแจ้งเตือน — เครื่องนี้เปิดทิ้งไว้ได้ทั้งคืน และอยู่ Wi-Fi เดียวกับกล้องไหมคะ?”

1. ใช่ เครื่องนี้เปิดตลอด [แนะนำ] → ไปต่อ
2. เครื่องนี้ใช้ลองก่อน เดี๋ยวย้ายไปเครื่องที่เปิดตลอด → ติดตั้งได้ บอกว่าย้ายทีหลังได้ (ก๊อปทั้งโฟลเดอร์ รวม `.env` และ `data/`)
3. ไม่แน่ใจว่าอยู่ Wi-Fi เดียวกับกล้องไหม → ดู IP เครื่อง (`ipconfig getifaddr en0` / `ipconfig`) กับ IP กล้องในแอปกล้อง ต้องขึ้นต้นเหมือนกัน เช่น 192.168.1.x

ต่อด้วย: “ติดตั้งไว้ที่โฟลเดอร์ไหนดีคะ? (ค่าเริ่มต้น ~/nongfon)”

## ขั้น 3 — สมองของน้องฝน

> “มี API key หรือแพ็กเกจ AI อยู่แล้วหรือยังคะ?”

| ตัวเลือก | ค่าใช้จ่าย | ทำอะไรต่อ |
| --- | --- | --- |
| 1) OpenAI (GPT) [แนะนำ] | ราว 170 บาท/เดือน (กล้อง 3 ตัว ตรวจทุก 10 นาที) | `set-env AI_ENGINE=openai AI_MODEL=gpt-6-luna` |
| 2) Claude API | ราว $50–85/เดือน (Sonnet) · ถูกกว่าด้วย Haiku | `set-env AI_ENGINE=anthropic AI_MODEL=claude-sonnet-5` |
| 3) แพ็กเกจ Claude Pro/Max | ไม่เสียค่า API เพิ่ม (ใช้โควตาแพ็กเกจ) | `set-env AI_ENGINE=claude-code` + ต้องมีคำสั่ง `claude` ในเครื่อง |
| 4) ยังไม่มี | ฟรี | `set-env DEMO=1` — ลองโหมดสาธิตก่อน |

ถ้ายังไม่มีคีย์ บอกวิธีสร้าง (ผู้ใช้ทำเองทั้งหมด):

- **OpenAI:** platform.openai.com/api-keys → Create new secret key → คัดลอก · เติมเครดิตที่ Settings → Billing ($5 ก็พอเริ่ม)
- **Claude API:** console.anthropic.com → API Keys → Create Key · เติมเครดิตที่ Billing
- **Claude Pro/Max:** ติดตั้ง Claude Code แล้วพิมพ์ `claude setup-token` ใน Terminal ของตัวเอง → ได้โทเคน `sk-ant-oat01-…`

จากนั้น: “เปิด Terminal ของคุณเอง แล้วพิมพ์ `cd <โฟลเดอร์> && bash install/nongfon.sh secrets` นะคะ (Windows: ดับเบิลคลิก NongFon-windows.bat แล้วเลือก 3) วางคีย์ตอนที่ถาม (ตัวอักษรจะไม่ขึ้นบนจอ)
ตัวช่วยจะตรวจคีย์กับผู้ให้บริการให้ทันที และตั้งรหัสผ่านหน้าเว็บให้ด้วย — จดรหัสผ่านไว้นะคะ เสร็จแล้วพิมพ์บอกว่า ‘เสร็จแล้ว’”

## ขั้น 4 — ช่องทางปลุก

> “อยากให้น้องฝนปลุกทางไหนบ้างคะ? เลือกได้หลายข้อ”

1. **Telegram** [แนะนำ ฟรี ส่งรูปกล้อง + มีปุ่มหยุดไซเรน]
   - ทัก **@BotFather** → `/newbot` → ตั้งชื่อ → ตั้ง username ที่ลงท้ายด้วย `bot` → ได้โทเคนบอท
   - เปิดแชทกับบอทแล้วกด **Start** · ถ้าอยากให้ทั้งบ้านได้รับ: สร้างกลุ่ม เชิญคนในบ้าน + บอท แล้วพิมพ์ `/start` ในกลุ่ม
   - โทเคนผู้ใช้ใส่เองด้วยคำสั่งเดียวกับขั้น 3 · หลังเปิดน้องฝน: หน้าเว็บ → ตั้งค่า → Telegram → **ใช้แชทนี้** → ส่งข้อความทดสอบ
   - บอท 1 ตัวใช้กับน้องฝนเท่านั้น (ถ้าบอทต่อกับโปรแกรมอื่นอยู่ จะขึ้นว่า “บอทนี้ถูกใช้ที่อื่น”)
2. **iPhone ดังแม้ปิดเสียง (Pushover)** — ทดลองฟรี 30 วัน แล้วจ่ายครั้งเดียว $4.99 ใช้ได้ทุก iPhone ในบัญชีเดียวกัน
   - ลงแอป Pushover Notifications (App Store) → สมัครบัญชี → อนุญาตการแจ้งเตือน + **Critical Alerts**
   - **ยืนยันอีเมลจาก Pushover ก่อน** (ถ้ายังไม่ยืนยัน จะสร้างแอปไม่ได้)
   - pushover.net → Create an Application/API Token → ชื่อ “น้องฝน” → ได้ **API Token (ขึ้นต้น a)**
   - **User Key (ขึ้นต้น u)** อยู่มุมขวาบนของ pushover.net — ระวังอย่าวาง User Key ในช่อง Token
   - ในแอป: Settings → Emergency Priority → เปิด **Override Silent Mode**
   - คนอื่นในบ้าน: ลงแอปแล้ว **Login บัญชีเดียวกัน** ตั้งชื่อเครื่องใหม่ → ดังพร้อมกัน ใครแตะรับทราบก่อน อีกเครื่องหยุดด้วย
3. **LINE OA** — ต้องมี LINE Official Account ของตัวเอง → LINE Developers → Messaging API → Channel access token (long-lived)
   (แพ็กเกจฟรีมีโควตาข้อความต่อเดือนจำกัด)
4. **มือถือ/แท็บเล็ตเก่าข้างเตียง** — เปิดหน้าเว็บน้องฝนในเครื่องนั้น → หน้า “ข้างเตียง” → แตะ “เปิดเสียงเตือน” เสียบชาร์จทิ้งไว้
5. **ไซเรนจริง** — Zigbee ผ่าน zigbee2mqtt (`MQTT_URL`) หรือปลั๊ก/ไซเรนที่สั่งผ่านลิงก์ (Shelly, Tasmota, Home Assistant)
   ให้ผู้ใช้แก้ใน `.env` เองตาม `docs/notify.md` (ลิงก์มีรหัสอยู่ อย่าส่งในแชท)

## ขั้น 5 — บ้านของคุณ

> “ตั้งชื่อบ้านว่าอะไรดีคะ? (ขึ้นในข้อความเตือน)” → `SITE_NAME`
> “บ้านอยู่ย่าน/อำเภอไหนคะ? ใส่แค่ระดับย่านพอ ไม่ต้องถึงบ้านเลขที่ — ใช้ดูเรดาร์ฝนรอบบ้านและข่าวน้ำท่วมแถวนั้น”

หาพิกัดด้วยชื่อภาษาอังกฤษ (Open-Meteo ค้นชื่อไทยไม่เจอ):
`curl -s "https://geocoding-api.open-meteo.com/v1/search?name=Bang%20Yai&count=5&language=th"` → ให้ผู้ใช้เลือก → ตั้ง
`LATITUDE`, `LONGITUDE` (ทศนิยม 2–3 ตำแหน่งพอ) และ `NEWS_QUERY="น้ำท่วม บางใหญ่ นนทบุรี"`

## ขั้น 7 — กล้อง

> “กล้องยี่ห้ออะไร มีกี่ตัว และต่อกับเครื่องบันทึก (NVR/DVR) หรือเปล่าคะ?”

- ทางง่ายสุด: หน้าเว็บ → ตั้งค่า → กล้อง → **ค้นหากล้องในบ้าน** → เลือกกล้อง → ผู้ใช้พิมพ์ชื่อผู้ใช้/รหัสกล้องเอง
- ยี่ห้อที่หาลิงก์ให้อัตโนมัติ: Dahua/Imou/RISCO, Hikvision/HiLook, Foscam, Reolink, TP-Link Tapo/VIGI, Tiandy, Uniview, ONVIF ทั่วไป
- Tapo: ต้องตั้ง “Camera Account” ในแอป Tapo ก่อน (Advanced Settings) · EZVIZ/HiLook: ใช้รหัสยืนยันบนสติกเกอร์กล้อง
- Xiaomi/Mi Home: ต้องผ่าน go2rtc (ดู `docs/cameras.md`)
- แนะนำให้สร้าง **บัญชีกล้องแยกให้น้องฝน สิทธิ์ดูภาพอย่างเดียว** (ถ้ากล้อง/NVR รองรับ) — รหัสนี้ถูกเก็บในเครื่องและใช้ดึงภาพเท่านั้น
- แนะนำให้ตั้ง **IP คงที่** ให้กล้องในเราเตอร์ (DHCP reservation)
- หันกล้องให้เห็นพื้นที่น้ำจะมาก่อน และจุดที่ใช้ขีดเส้นได้ชัดทั้งกลางวันและกลางคืน

## ขั้น 8 — ขีดเส้น

> “ขอภาพหน้าจอหน้า ‘ขีดเส้น’ ของแต่ละกล้องหน่อยค่ะ เดี๋ยวช่วยดูว่าควรขีดตรงไหน”

หลักการที่ต้องอธิบาย:

- **เส้นแดง** = จุดที่ถ้าน้ำถึงแล้วต้องตื่นมาทำอะไรจริง (ยกของ ย้ายรถ ปิดประตูกันน้ำ) — ควรมีอย่างน้อย 1 กล้อง
- **เส้นเหลือง** = ต่ำกว่าเส้นแดงพอให้มีเวลาเตรียมตัว (เช่น ขอบถนน/ขอบฟุตบาท)
- **เส้นเขียว** = ระดับที่ถือว่าน้ำลดแล้ว (น้องฝนจะบอกว่า “น้ำลดแล้ว” เมื่อกลับมาถึงเส้นนี้)
- ขีดบนสิ่งที่ไม่ขยับและเห็นชัดทั้งกลางวันกลางคืน (ขั้นบันได ขอบผนัง เสา) · เลี่ยงพื้นที่แสงไฟสะท้อนแรง
- กล้องที่มีเส้นแดง = “กล้องตัดสิน” · เขียน “โน้ตกล้อง” อธิบายสิ่งที่ทำให้ AI สับสน (เช่น ท่อระบายน้ำ แอ่งน้ำฝนปกติ)
- เก็บ **ภาพอ้างอิงตอนแห้ง** กลางวัน 1 ภาพ กลางคืน 1 ภาพ
