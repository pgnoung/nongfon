# แก้ปัญหา

เริ่มจาก `npm run doctor -- --online` เสมอ แล้วแก้ทีละข้อ ❌ ก่อน ⚠️ — ห้ามเปิดอ่าน `.env` ในแชท

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
| --- | --- | --- |
| ดับเบิลคลิก `.command` แล้ว Mac บอกว่าเปิดไม่ได้ | ไฟล์มาจากอินเทอร์เน็ต (Gatekeeper) | System Settings → Privacy & Security → **Open Anyway** หรือใช้คำสั่งติดตั้งบรรทัดเดียว |
| กล้องขึ้น “No route to host” / “EHOSTUNREACH” บน Mac | Terminal ยังไม่ได้รับอนุญาตให้เข้าเครือข่ายในบ้าน | System Settings → Privacy & Security → **Local Network** → เปิด Terminal แล้วเปิดน้องฝนใหม่ |
| “ไม่พบโปรแกรม ffmpeg” | เครื่องไม่มี ffmpeg (ใช้กับกล้อง rtsp://) | รันตัวติดตั้งอีกครั้ง (เติมให้เอง) หรือ `npm install --no-save ffmpeg-static` หรือใช้ลิงก์ภาพนิ่ง http:// |
| “กล้องไม่ตอบภายใน 20 วินาที” | IP ผิด / คนละวง LAN / กล้องจำกัดคนดูพร้อมกัน | ตรวจ IP ในแอปกล้อง · ปิดแอปดูสดอื่นชั่วคราว · หน้าเว็บ → ตั้งค่า → กล้อง → ทดสอบ |
| “กล้องไม่ยอมให้เข้า (HTTP 401)” | ชื่อผู้ใช้/รหัสผิด | รหัสที่มีอักขระพิเศษ เช่น `@` ต้องเขียน `%40` · Tapo ใช้ Camera Account ไม่ใช่รหัสแอป |
| เครื่องบันทึก (NVR) ตอบ HTTP 500 เป็นบางครั้ง | ขอภาพหลายกล้องพร้อมกัน | ลดจำนวนกล้องที่ดูสดพร้อมกัน · Mac/Linux ถ้ายังเป็น ตั้ง `node scripts/set-env.js HTTP_TOOL=curl` (ดึงทีละกล้อง) |
| คีย์ AI ไม่ผ่าน / “เครดิตไม่พอ” | คีย์ผิด ถูกยกเลิก หรือยังไม่เติมเครดิต | ตรวจยอดที่หน้าผู้ให้บริการ → ตัวเปิดน้องฝน → เมนู 3 วางคีย์ใหม่ |
| OpenAI ตอบว่าเรียกโมเดลไม่ได้ (404) | บัญชียังไม่มีสิทธิ์โมเดลนั้น | เติมเครดิตก่อน หรือเปลี่ยนโมเดลในหน้าตั้งค่า |
| Telegram เงียบ | ยังไม่ได้ Start บอท หรือยังไม่ได้ผูกแชท | ทักบอท/พิมพ์ `/start` ในกลุ่ม → หน้าเว็บ → ตั้งค่า → Telegram → **ใช้แชทนี้** |
| “บอทนี้ถูกใช้ที่อื่นอยู่” | บอทตัวเดียวกันต่อกับโปรแกรมอื่น (webhook) | สร้างบอทใหม่ให้น้องฝนโดยเฉพาะ |
| Pushover “application token is invalid” | วาง User Key (u…) ในช่อง Token หรือยังไม่ได้สร้างแอป | สร้างแอปที่ pushover.net (ต้องยืนยันอีเมลก่อน) → Token ขึ้นต้น a → ตัวเปิดน้องฝน → เมนู 3 |
| iPhone ไม่ดังตอนปิดเสียง | ยังไม่เปิด Critical Alerts | แอป Pushover → Settings → Emergency Priority → Override Silent Mode · iPhone Settings → Notifications → Pushover → Critical Alerts |
| เปิดหน้าเว็บไม่ได้ / พอร์ตชน | มีโปรแกรมอื่นใช้พอร์ต 8080 | `node scripts/set-env.js PORT=8090` แล้วเปิดน้องฝนใหม่ |
| ลืมรหัสผ่านหน้าเว็บ | — | ผู้ใช้เปิดไฟล์ `.env` ดูบรรทัด `DASHBOARD_PASSWORD` เอง หรือตัวเปิดน้องฝน → เมนู 3 ตั้งใหม่ |
| กลางคืนเตือนผิดบ่อย | แสงสะท้อน ฝนเกาะเลนส์ | เก็บภาพอ้างอิงกลางคืน · ขีดเส้นบนขอบที่ชัด · เขียนโน้ตกล้อง · เปิด “ยืนยันเส้นเหลืองก่อนเตือน” · ลองโมเดลที่แม่นขึ้น |
| Windows แสดงภาษาไทยเป็นสี่เหลี่ยม | คอนโซลเก่าไม่มีฟอนต์ไทย | เปิดด้วย Windows Terminal · หรือดูผลในหน้าเว็บแทน |
| เครื่องหลับแล้วน้องฝนหยุด | ตั้งค่าพลังงาน | macOS: Energy → Prevent automatic sleeping · Windows: Sleep = Never · `npm run autostart -- on` |
