# ต่อยอดน้องฝน

เสนอเป็นเมนูให้ผู้ใช้เลือก ทำทีละเรื่อง และพิสูจน์ผลทุกครั้ง (`npm run doctor`, `npm test`, หรือผู้ใช้ยืนยันว่าได้รับ)

## ปรับได้จากหน้าเว็บ (ไม่ต้องแก้โค้ด)

1. **เพิ่มกล้อง / ขีดเส้นใหม่ / ภาพอ้างอิง** — ตั้งค่า → กล้อง · หน้า “ขีดเส้น”
2. **ความถี่การตรวจ** (ตั้งค่า → รอบการตรวจ) — ปกติ ~10 นาที · ถี่ขึ้นเองเมื่อน้ำเลยเส้นเขียว · ห่างขึ้นเมื่อพยากรณ์ว่าไม่มีฝน
3. **ยืนยันเส้นเหลืองก่อนเตือน** (ตั้งค่า → เกณฑ์ตัดสิน) — กันเตือนผิดจากแสงสะท้อน (ตรวจซ้ำก่อนส่ง)
4. **สรุปทุกชั่วโมง** (ตั้งค่า → แจ้งเตือนเรื่องอะไรบ้าง) — อากาศ ฝนรอบบ้าน ข่าวน้ำท่วมแถวบ้าน พร้อมรูปกล้อง (ไม่เสียค่า AI)
5. **เปลี่ยนโมเดล AI** (ตั้งค่า → สมองของน้องฝน) — ดูค่าใช้จ่ายจริงในการ์ด “ค่า AI” หน้าแรก
6. **เตือนซ้ำทุกกี่นาที** (ตั้งค่า → เกณฑ์ตัดสิน) · **ปลุก iPhone ตั้งแต่เส้นเหลือง** (ตั้งค่า → ไซเรนปลุก)

## ต่อระบบอื่น (แก้ `.env` + เปิดใหม่)

- **ดูจากนอกบ้านแบบปลอดภัย:** ลง [Tailscale](https://tailscale.com) ในเครื่องที่รันน้องฝนและมือถือ ล็อกอินบัญชีเดียวกัน
  → เปิด `http://<ชื่อเครื่องใน Tailscale>:<PORT>` ได้จากทุกที่ ไม่ต้องเปิดพอร์ต
  (ขั้นสูง: Cloudflare Tunnel + Access แล้วตั้ง `CF_ACCESS_TEAM_DOMAIN`, `CF_ACCESS_AUD` — น้องฝนรับการล็อกอินของ Access แทนรหัสผ่าน)
- **ส่งต่อให้ Make / n8n / Home Assistant:** `WEBHOOK_URL` — ทุกการเตือนจะ POST JSON ไปที่ลิงก์นี้
- **ไซเรน Zigbee / ปลั๊กอัจฉริยะ:** `MQTT_URL` หรือ `SIREN_WEBHOOK_ON_URL` / `SIREN_WEBHOOK_OFF_URL` (ดู `docs/notify.md`)
- **ย้ายไปเครื่องที่เปิดตลอด (เช่น Mac mini):** ก๊อปทั้งโฟลเดอร์รวม `.env` และ `data/` → รันตัวติดตั้งที่เครื่องใหม่ → `npm run autostart -- on`

## แก้โค้ด (สำหรับคนอยากเรียนรู้ต่อ)

| อยากทำ | ไฟล์ที่เกี่ยวข้อง |
| --- | --- |
| รอบการตรวจ ดึงภาพ เก็บผล | `src/watcher.js` |
| กติกาตัดสินสถานะจากเส้น (เหลือง/แดง/เขียว) | `src/judge.js` |
| เมื่อไหร่ส่งเตือน ตรวจซ้ำ เตือนซ้ำ | `src/alerts.js` |
| ช่องทางส่งข้อความ | `src/notify/` (telegram, line, webhook, messages) |
| คำสั่งในแชท Telegram (/status /check /stop …) | `src/notify/telegram-bot.js` |
| ไซเรนและ iPhone | `src/siren/siren.js` |
| คำสั่ง AI และรูปแบบคำตอบ | `src/ai/prompt.js`, `src/ai/*.js` |
| ดึงภาพกล้อง / ดูสด / วาดเส้นบนภาพ | `src/camera/` |
| หน้าเว็บ | `public/` (HTML/CSS/JS ไม่มีขั้น build) · API อยู่ที่ `src/web/server.js` |

ตัวอย่างงานต่อยอดที่เหมาะกับการฝึก:

1. **เพิ่มช่องทางแจ้งเตือนใหม่** (เช่น Discord webhook): สร้าง `src/notify/discord.js` ตามแบบ `line.js` → เพิ่มใน `src/notify/index.js`
   → เพิ่มค่าใน `.env.example` → เขียนเทสต์ใน `test/notify.test.js` → `npm test`
2. **เพิ่มคำสั่งในบอท Telegram** เช่น `/photo` ส่งภาพล่าสุดทุกกล้อง → `src/notify/telegram-bot.js` + เทสต์
3. **ปรับบุคลิกข้อความเตือน** ให้เข้ากับบ้าน → `src/notify/messages.js` (คงข้อมูลสำคัญ: ระดับ กล้อง เวลา วิธีหยุดไซเรน)
4. **ปรับธีมหน้าเว็บ** → สีอยู่ใน `public/css/app.css` (ตัวแปร `--rain` ฯลฯ) · ตัวละครดู `docs/character.md`

กติกาเมื่อแก้โค้ด: เขียนเทสต์ก่อน · `npm test` ต้องผ่านทั้งหมด · คงความปลอดภัยของการปลุก (เส้นแดงชนะ ตรวจซ้ำก่อนปลุก
มองไม่เห็นต้องบอกว่ามองไม่เห็น) · ห้ามใส่ค่าลับในโค้ดหรือ log
