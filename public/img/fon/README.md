# ภาพจริงของน้องฝน (official artwork)

ไฟล์ในโฟลเดอร์นี้ทำจากแพ็กเกจภาพตัวละครน้องฝน (อย่าแก้มือ ให้สร้างใหม่จากแพ็กเกจภาพ):

- `happy` `watch` `alarm` `confused` `sleep` `relief` `scan` `.webp` — 7 อารมณ์ อยู่บนผืนขนาดเดียวกัน (697×900) ตัวสูงเท่ากัน เท้าอยู่ที่เดียวกัน
  สร้างด้วย `tools/cutout.py --app <nongfon>`
- `face.webp` — หน้าและไหล่ (512×512) · `avatar.webp` — หน้าในวงกลม (256×256) สร้างด้วย `tools/icons.py --app <nongfon>`
- `manifest.json` — บอกแอปว่ามีภาพอารมณ์ไหนบ้าง อารมณ์ที่ไม่มีในรายการ แอปจะใช้น้องฝนแบบเวกเตอร์ (`public/js/mascot.js`) แทน

ตัวละครและกติกา (เลนส์ฝนอยู่ฝั่งซ้ายของภาพเสมอ ห้ามกลับด้าน): `docs/character.md`
